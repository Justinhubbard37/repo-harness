- `rh init` no longer writes the `check:brain` and `sync:brain` package scripts. The next `rh init` removes each of them from `package.json` when its value is a released value (`rh brain check`, `rh brain sync`, or the older `repo-harness brain` form), and keeps a custom value with a notice. Run `rh brain check` and `rh brain sync` directly. (#2795)
